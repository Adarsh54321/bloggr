Bloggr 🚀

A simple full-stack blogging platform built using HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB.

🌐 Live Website: https://bloggrchatx.netlify.app/

Features

- User Registration & Login
- Create Blog Posts
- Responsive UI
- MongoDB Database
- Netlify + Render Deployment

Common Issues Faced

- MongoDB connection errors
- CORS configuration problems
- Backend deployment issues on Render
- API endpoint mismatches
- Netlify frontend deployment fixes

Tech Stack

HTML • CSS • JavaScript • Node.js • Express.js • MongoDB

Built by Adarsh Palo as a learning project to explore full-stack web development.
